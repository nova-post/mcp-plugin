# Nova Post Skills

Набір [Agent Skills](https://agentskills.io/) і MCP-сервер для роботи з доставкою Nova Post
у Claude, Codex та ChatGPT: пошук відділень, розрахунок вартості, створення й відстеження
відправлень, отримання офіційних документів.

## Встановлення

Встановлюйте плагін через marketplace, щоб отримати і skills, і конфігурацію MCP-сервера.
Усі клієнти використовують спільну папку [skills/](skills/).

### Codex

Склонуйте цей репозиторій із GitHub у постійну локальну папку, додайте її
як marketplace і встановіть плагін. У команді вкажіть абсолютний шлях до вашої копії:

```bash
codex plugin marketplace add /absolute/path/to/nova-post
codex plugin add nova-post@nova-post
```

Після встановлення почніть нову сесію Codex та пройдіть авторизацію Nova Post,
коли клієнт її запропонує.

### Claude Code

Додайте локальну копію цього репозиторію як marketplace і встановіть плагін:

```text
/plugin marketplace add /absolute/path/to/nova-post
/plugin install nova-post@nova-post
```

Після встановлення виконайте `/mcp`, оберіть `nova-post` і увійдіть у свій акаунт Nova Post.

### ChatGPT Desktop

Для локального використання в Work або Codex додайте репозиторій як marketplace за
інструкцією для Codex вище. Перезапустіть ChatGPT Desktop, відкрийте каталог **Plugins**,
оберіть джерело **Nova Post** та встановіть `nova-post`.

Якщо ви отримали ZIP, спочатку розпакуйте його в постійну папку й передайте її абсолютний
шлях команді `codex plugin marketplace add`. Прикріплення ZIP до повідомлення в чаті
не встановлює плагін.

Локальні marketplace призначені для підтримуваних desktop-клієнтів. Вебверсія ChatGPT
не читає локальні файли Codex. Для роботи з віддаленим MCP у ChatGPT можна створити
власне підключення через **Plugins → + → Add custom MCP server**, вказавши
`https://mcp.novapost.com/mcp`. Власне MCP-підключення налаштовується окремо від встановлення skills.
Доступність встановлення та власних MCP-підключень залежить від акаунта й політик workspace.

Детальніше: [локальні marketplace](https://developers.openai.com/plugins/build/plugins#how-local-marketplaces-work)
і [тестування плагіна з MCP](https://developers.openai.com/plugins/build/plugins#create-and-test-a-plugin-locally-with-an-mcp-server).

### Інші клієнти Agent Skills

Клієнти з підтримкою Agent Skills можуть використовувати папки з [skills/](skills/)
відповідно до власних правил встановлення. Копіювання skills окремо не підключає MCP-сервер:
його потрібно налаштувати й авторизувати в клієнті. Спосіб виклику skills та імена
MCP-інструментів залежать від клієнта; сумісність цих сценаріїв з іншими клієнтами не перевірена.

## Skills

Асистент підбирає skill за змістом розмови. Опишіть задачу звичайною мовою;
у Claude Code також можна викликати skill командою `/nova-post:<назва>`.

| Skill | Для чого |
|---|---|
| [branches](skills/branches/SKILL.md) | До трьох працюючих відділень або поштоматів у місті чи біля адреси з графіком роботи |
| [calculate](skills/calculate/SKILL.md) | Вартість, сервіс і орієнтовна дата доставки по Україні або за кордон без створення відправлення |
| [ship](skills/ship/SKILL.md) | Покрокове створення відправлення: збір даних, розрахунок і підтвердження користувача |
| [shipments](skills/shipments/SKILL.md) | Перелік створених з акаунта відправлень та їхні статуси; вхідні посилки — за відомими номерами |
| [track](skills/track/SKILL.md) | Поточний статус, місцезнаходження, очікувана дата доставки та історія переміщення |
| [documents](skills/documents/SKILL.md) | Посилання на офіційні PDF: маркування, міжнародні документи та інвойс |

### Приклади запитів

```text
Знайди три найближчі відділення біля київського ЦУМу, з яких можна відправити посилку.
Порахуй доставку 1 кг, 20×15×10 см, з відділення №1 у Києві до відділення №1 у Львові.
Допоможи створити відправлення з Києва до Варшави.
Покажи мої відправлені посилки та їхні статуси.
Відстеж відправлення 20450000000000 та покажи історію переміщення.
Дай посилання на етикетку для відправлення 20450000000000 у форматі A4.
```

Приклади команд Claude Code:

```text
/nova-post:branches Київ Хрещатик
/nova-post:track 20450000000000 history
/nova-post:documents 20450000000000 marking A4
```

## MCP-сервер

Плагін містить конфігурацію віддаленого MCP-сервера Nova Post:

| Сервер | Endpoint | Призначення |
|---|---|---|
| `nova-post` | `https://mcp.novapost.com/mcp` | Відділення, розрахунок доставки, створення, перегляд, відстеження й видалення відправлень, офіційні документи та митні довідники |

Сервер не повертає повного переліку посилок, адресованих користувачу. Для відстеження
вхідних відправлень потрібні їхні номери. Видалення доступне через MCP після явного
підтвердження; окремого skill для нього немає.

### Авторизація та безпека

- Вхід Nova Post використовує OTP і підтвердження доступу. API-ключ не потрібно вводити в чат.
- Токени Nova Post зберігаються на сервері; клієнт отримує окремий токен доступу до Nova Post MCP.
- Сервер надає визначений набір операцій і вилучає з відповідей персональні дані, які не потрібні асистенту.
- Створення та видалення відправлень потребують явного підтвердження користувача.
- Конфігураційні файли плагіна не містять облікових даних або токенів.

[Політика конфіденційності](https://mcp.novapost.com/policies/privacy).

## Структура плагіна

Пакет використовує [Agent Plugins 1.0.0](https://agent-plugins.org/specification)
і містить сумісні конфігурації Claude та Codex:

| Шлях | Призначення |
|---|---|
| [plugin.json](plugin.json) | Основний переносимий маніфест: назва, версія й метадані |
| [mcp.json](mcp.json) | Переносима конфігурація MCP з транспортом `streamable-http` |
| [skills/](skills/) | Шість спільних сценаріїв Agent Skills |
| [.codex-plugin/plugin.json](.codex-plugin/plugin.json) | Сумісний маніфест Codex з метаданими інтерфейсу та посиланнями на skills і MCP |
| [.claude-plugin/plugin.json](.claude-plugin/plugin.json) | Маніфест Claude |
| [.claude-plugin/marketplace.json](.claude-plugin/marketplace.json) | Marketplace Claude |
| [.mcp.json](.mcp.json) | MCP-конфігурація Claude та сумісного маніфесту Codex з транспортом `http` |
